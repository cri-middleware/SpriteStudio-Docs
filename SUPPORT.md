# Support Guide

Thank you for using the SpriteStudio documentation portal! Please use the following channels to get help, report issues, or suggest improvements.

👉 **Looking for help with a player or the SDK, not with these docs?** The portal's [**Support page**](./docs/en/support.md) routes you to the right repository - it lists every project's issue tracker and how to tell a shared-core problem from an engine-specific one.

## 🛠️ GitHub Issues (Public)
For problems **with this portal** - a wrong or outdated description, a broken link, a missing translation, a build failure - please use [GitHub Issues](https://github.com/cri-middleware/SpriteStudio-Docs/issues).

*Note: issues about a player's own behavior belong in that player's repository, not here. This repository contains documentation only.*

Before opening a new issue, please search existing issues to see if your topic has already been discussed.

## ❓ Questions on How to Use SpriteStudio
If you have questions about how to use a player or the SDK, need implementation advice, or want to share tips with other developers, please use our official community forum:

👉 [**SpriteStudio Community**](https://spritestudio.jp/community/)

## 🔒 Private Inquiries & Data Submission
For private consultations, sensitive issue reports, or support with contractual guarantees, please use our official inquiry form:

👉 [**CRI Middleware Inquiry Form (English)**](https://www.webtech.co.jp/contact/en.html)

*Note: the English form has no file upload. To send large reproduction data (e.g., a `.sspj` project), use the [Japanese Help Center form](https://www.webtech.co.jp/help/ja/spritestudio7/inquiries/ssplayer_tool/), which takes a zip of up to 8 MB.*

## 日本語でのサポート (Support in Japanese)

SpriteStudio ドキュメントポータルをご利用いただきありがとうございます。ご質問や不具合の報告は、以下の窓口をご利用ください。

👉 **Player や SDK 自体について知りたい場合**は、ポータルの [**サポートページ**](./docs/ja/support.md) をご覧ください。各プロジェクトの Issue 窓口と、共通コア側の問題かエンジン固有の問題かを見分ける方法を掲載しています。

### 🛠️ GitHub Issues (公開)
**このポータルに関する**問題（記述の誤りや古い情報、リンク切れ、翻訳の欠落、ビルドの失敗など）は [GitHub Issues](https://github.com/cri-middleware/SpriteStudio-Docs/issues) へ投稿してください。

*注: 各 Player の動作に関する問題は、こちらではなく該当 Player のリポジトリへお願いします。このリポジトリはドキュメントのみを管理しています。*

投稿前に、同様の内容が既に報告されていないか、既存の Issue を検索してください。

### ❓ 使い方のご質問
Player や SDK の使い方に関するご質問、実装の相談、他の開発者との情報共有には、公式コミュニティをご利用ください。

👉 [**SpriteStudio コミュニティ**](https://spritestudio.jp/community/)

### 🔒 個別のお問い合わせ・データの送付
非公開でのご相談、機微な内容の報告、大容量の再現データ（`.sspj` プロジェクト等）の送付、契約に基づくサポートは、公式の **ヘルプセンター** をご利用ください。

👉 [**ヘルプセンター（お問い合わせフォーム）**](https://www.webtech.co.jp/help/ja/spritestudio7/inquiries/ssplayer_tool/)

*注: 再現データの送付には、フォーム内のファイルアップロード機能をご利用ください。*
