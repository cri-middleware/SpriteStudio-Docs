# 📖 用語集

このポータル、SDK、および各 Player のドキュメントで共通して使う用語をまとめます。パイプラインの
どちら側の言葉かで分類しています - SpriteStudio で制作するもの、SDK が生成・再生するもの。

## 🎨 制作 - SpriteStudio 7 側

| 用語 | 内容 |
|---|---|
| **プロジェクト**（`.sspj`） | SpriteStudio のプロジェクトファイル。アニメーションパック、セルマップ、エフェクト、サウンドなど他のすべてを参照し、変換時に参照解決のためだけに読まれます。変換後のアセットには格納されません。 |
| **アニメーションパック**（`.ssae`） | **パーツ**の集合と、それを動かす**アニメーション**の集合。**変換の単位**でもあり、`.ssae` 1 つが `.ssab` 1 つになります。 |
| **アニメーション** | アニメーションパック内の 1 本のタイムライン（`walk`、`attack` など）。再生時に名前で選択します。 |
| **パーツ** | アニメーションの階層を構成するノード。スプライト、ボーン、マスクなど。パーツは親子ツリーを成し、トランスフォームとカラー／不透明度は下方向に継承されます。 |
| **セル** | テクスチャ上の矩形領域。パーツが描画する画像そのものです。 |
| **セルマップ**（`.ssce`） | テクスチャと、その上に定義されたセルの集合。パーツはセルマップを介してセルを参照します。 |
| **エフェクト**（`.ssee`） | パーティクルエフェクトの定義。Effect パーツが再生します。 |
| **サウンド**（`.ssse`） | タイムライン上のオーディオイベントが参照するサウンド設定。 |
| **シーケンス**（`.ssqe`） | 複数のアニメーションをつなぐプレイリスト。`.ssqb` に変換されますが、ランタイムでの再生は未実装です（[共通の制限事項](./limitations.md)）。 |
| **ビットマップフォント**（`.fnt`） | Text パーツが描画に使う BMFont 形式のフォント。 |
| **ユーザーデータ／シグナル** | フレームに置くマーカー。ランタイムが**イベント**として通知するため、ゲームロジックや SE をフレーム精度で発火させるフックになります。 |
| **パーツカラー** | タイムライン上でパーツ単位に設定するカラーブレンド。パーツのテクスチャに重ねて適用されます。 |
| **`independent`** | インスタンスパーツ／エフェクトパーツに設定するフラグ。子を親のタイムラインから切り離し、自身のリアルタイム時計で進行させます。逆再生とシークに実際の影響があります（[共通の制限事項](./limitations.md)）。 |

### パーツ種別

以下の名前は SDK のスキーマと各 Player が使うものです。よく目にするものを挙げます。

| パーツ種別 | 描画対象 |
|---|---|
| `Normal` | セル（通常のスプライトパーツ）。 |
| `Mesh` | ボーンで変形するメッシュ（メッシュ＆デフォーム）。 |
| `Instance` | 別のアニメーションを内部に配置したもの。 |
| `Effect` | パーティクルエフェクト（`.ssee`）。 |
| `Mask` | 覆っているパーツをクリップするステンシル。 |
| `Shape` | 生成されるプリミティブ（矩形・三角形・星・矢印ほか）。 |
| `Text` | ビットマップフォントによるテキスト。 |
| `Nines` | ナインスライス（9 スライス）画像。 |
| `Armature` | ボーン。自身は何も描画せず、紐づいたパーツを動かします。 |

## ⚙️ ランタイム - SDK 側

| 用語 | 内容 |
|---|---|
| **`.ssab`**（SpriteStudio Anime Binary） | 変換済みで即再生できるアセット。アニメーションパック 1 つ分をコンパクトな FlatBuffers バイナリにしたもの。[フォーマット仕様](./format-spec.md) を参照。 |
| **`.ssqb`** | 変換済みのシーケンスバイナリ。`.ssqe` に対する `.ssab` 相当のもの。 |
| **`libssconverter`** | SDK の変換側。`.sspj` -> `.ssab` / `.ssqb`。すべての変換フロントエンドが同じコードを実行するため、どれを使っても出力は同一です。 |
| **`libssruntime`** | 再生側。現在フレームのタイムラインを評価し、結果をレンダラーへ渡します。 |
| **Brain / Body** | アーキテクチャ上の分担。**Brain**（`libssruntime`）がアニメーションの計算をすべて担いエンジン非依存、**Body**（各 Player）が Brain の計算結果を描画します。[SDK コンセプト](./concepts.md) を参照。 |
| **`FrameData`** | Brain が出力する **1 フレーム分**のデータ。実行時に生成される、そのまま描画できる密なデータで、ランタイムとレンダラー間のデータ交換インターフェースです。 |
| **`PartState`** | `FrameData` 内の 1 パーツ分の確定状態。位置、回転、α、メッシュ頂点などを含みます。 |
| **`DrawBatch`** | ランタイムが出力するエンジン非依存の描画プラン。何を、どの順で、どのブレンド／マスク状態で描くか。すべての Player が同じプランを消費することが、見た目の一貫性を担保しています。 |
| **Override Layer API** | 再生時にパーツの**カラー・セル参照・表示状態**を上書きするランタイム API。上書きはキーフレームにもブレンド結果にも優先します。 |
| **アニメーションブレンド／クロスフェード** | 複数のアニメーションを重み付きで同時再生する、または相互にフェードさせる機能。同一 `.ssab` 内に限られます（[共通の制限事項](./limitations.md)）。 |
| **サブフレーム補間** | フレームとフレームの間を評価する仕組み。制作時のフレームレートを超えても、またスローモーションでも滑らかに再生されます。 |
| **ネームハッシュ** | `.ssab` 内の名前付き要素はすべて名前の 32bit ハッシュを持ち、ランタイムは文字列比較なしで解決します。 |
| **embedded モード** | 参照アセットを `.ssab` 自身に埋め込む変換モード。注意点があります（[共通の制限事項](./limitations.md)）。 |
| **外部インスタンス** | *別の* `.ssab` にあるアニメーションを配置したインスタンスパーツ。参照先のファイルは別途用意する必要があります。 |
| **`no_std`** | コアが採用する Rust のモード。OS も標準ライブラリも使わないため、組込機器からブラウザまで動作します。 |
