# 🖥️ SSConverterGUI

`libssconverter` をラップした **デスクトップアプリ**（Tauri）です。CLI を使わずに `.sspj`
プロジェクトをランタイム用アセットへ変換できます。配布しているビルドは **macOS と Windows**
です。Linux では SDK の `ssconverter-cli` を使ってください（窓が無いだけで、同じ
`libssconverter` です）。

- **ドキュメント:** 🚧 _準備中_
- **リポジトリ:** <https://github.com/cri-middleware/SSConverterGUI>

これらのアセットが供給される変換パイプラインについては [SDK コンセプト](../sdk/concepts.md) を参照してください。
