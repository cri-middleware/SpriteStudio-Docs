# 🖥️ SSConverterGUI

`libssconverter` をラップしたクロスプラットフォームの **デスクトップアプリ**（Tauri）です。
CLI を使わずに `.sspj` プロジェクトをランタイム用アセットへ変換できます。

- **ドキュメント:** <https://cri-middleware.github.io/SSConverterGUI/>
- **リポジトリ:** <https://github.com/cri-middleware/SSConverterGUI>

これらのアセットが供給される変換パイプラインについては [SDK コンセプト](../sdk/concepts.md) を参照してください。
