# SSPlayerForGodot

**Godot Engine** でネイティブに SpriteStudio アニメーションを描画する **GDExtension** です。
`libssruntime` を基盤とします。

- **ドキュメント:** <https://cri-middleware.github.io/SSPlayerForGodot/>
- **リポジトリ:** <https://github.com/cri-middleware/SSPlayerForGodot>

プレイヤーの比較は [プラットフォームの選び方](../overview/choose-your-platform.md) を、
全プレイヤー共通の変換／再生パイプラインは [SDK コンセプト](../sdk/concepts.md) を参照してください。
