# ▶️ Try It in Your Browser

See SpriteStudio conversion and playback running live - **no install, nothing to set up**.
Everything here runs entirely in your browser. Each item is hosted on its player's own
site; this page just gathers the links.

!!! info "Coming soon"
    These demos and the hosted converter publish alongside each player's own site. The links
    below go live then.

## 🔄 Convert in your browser

**ssconverter-web** converts
your `.sspj` into `.ssab` right in the browser: the whole pipeline runs locally on WebAssembly,
so nothing is ever uploaded to a server. For the step-by-step walkthrough (and the desktop /
CLI alternatives), see [Converting with a Standalone Tool](./convert-with-a-standalone-tool.md).
