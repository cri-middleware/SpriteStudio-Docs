# 📱 SSPlayerForFlutter

Play SpriteStudio 7 animations in **Flutter** apps, backed by `libssruntime`. The
`SpriteStudioView` widget composites like any other widget, across Flutter's targets.

- **Documentation:** _coming soon_
- **Repository:** <https://github.com/cri-middleware/SSPlayerForFlutter>

Alongside the player it ships:

- **A [Flame](https://flame-engine.org/) adapter** - drop an animation into a Flame game.
- **A bundled `ssconvert` CLI** - turns `.sspj` projects into `.ssab`.
- **Live reload** - editor edits land in a running app.

See [Choose Your Platform](../overview/choose-your-platform.md) to compare players, or
[SDK Concepts](../sdk/concepts.md) for the conversion/playback pipeline shared across all of them.
